使用方法：
1. 在 test-pages 目录下启动 HTTP 服务器：python3 -m http.server 8765
2. 在 Chrome 中访问 http://localhost:8765/test-pages/
3. 打开 MayWatch 扩展 popup，添加监控任务并开启数值追踪
4. 使用 1-2 秒间隔观察趋势图是否正确渲染
5. 对于 placeholder 页面，点击"模拟刷新"验证占位值不会被误记录
