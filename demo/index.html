怎么用：
1. 在 Chrome 加载本扩展（chrome://extensions → 加载已解压）。
2. 打开任一 demo 页，右键某个数值元素 → 用 MayWatch 监控此元素，或在 Popup 手动填选择器。
3. 开启数值追踪，按下表选择模式：
  • #online-count 在线人数 → 整数 / 自动
  • #latency 响应延迟 → 带单位，或正则 (\d+)ms
  • #cpu CPU → 带单位（%）
  • #load 负载 → 小数
  • #price 价格 → 货币
  • #stock 库存 → 整数（刷新时会先变 —，验证占位兼容）
4. 数值变化 ≥ 1 次即应出现趋势图（首次快照已记录基线点），而非只有 diff。
